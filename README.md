# 果冻桌宠（JellyPet）

一个 macOS 桌面果冻挂件，图标可以在 Claude / GPT / Gemini 之间切换。没有待机动画，就一个标志放在那里。
按下去会以按压点为中心整体放大一点点，按压点附近轻微肿起；拖开时形状朝光标被拉长；
松开后全部 Q 弹归位。窗口本身从头到尾不动。

## 交互

| 操作 | 结果 |
| --- | --- |
| 按住标志 | 以按压点为中心整体放大（带一点冲过头），按压点附近同时肿起一块，越往外越接近原样 |
| 按住移动 | 肿起的中心跟着鼠标走；拖开的距离让形状只朝光标那一侧拉长（最多约 1.6 倍）、远端保持不动；越接近上限越拉不动 |
| 松手 | 整体缩放和拉动一起弹回，先反向缩一下（凹坑）、再荡两下 |
| 右键标志 | 图标（Claude / GPT / Gemini）、回到原位、大小（小·中·大）、退出 |

- 没有待机动画：静止时计时器完全停掉，CPU 占用 0%。
- 全程零位移：窗口坐标在按压、拖动全程不变，实测最大位移 0 pt。
- 窗口只在标志附近接收点击，四周的透明区域把点击让给桌面。
- 位置、大小、选中的图标记在用户偏好里，下次启动保持原样。
- 窗口在所有桌面空间和全屏应用之上，不占 Dock 图标。

## 安装

需要 Apple Silicon Mac + macOS 14 或更新版本。

```bash
./install.sh --build      # 编译 + 装进「应用程序」+ 启动
./install.sh --uninstall  # 退出并删除，设置保留
```

只编译不安装：

```bash
./build.sh                # 产物 build/JellyPet.app，编译后自动跑自检
./build.sh --package      # 另外产出 dist/ 下的 zip、dmg、sha256
```

需要 Xcode Command Line Tools（`xcode-select --install`），不需要完整 Xcode。

## 手感是怎么来的

全部状态在 `Sources/Jelly.swift`，两个阻尼弹簧：一个管按压（整体放大 + 局部肿起），
一个管拉动（形变归零）。果冻感来自**欠阻尼**：弹簧会冲过目标、再荡回来。

| 参数 | 值 | 影响 |
| --- | --- | --- |
| 按压弹簧刚度 / 阻尼 | 340 / 8.5 | 按下去的弹跳和松开后的余震。阻尼比约 0.23，按下冲到 1.34 倍，松开会来回过零 5 次 |
| 整体放大幅度 | ×1.20 | 以按压点为中心的整体缩放，按满时图标大两成；一拉开就平滑淡出（约 0.25 秒） |
| 局部肿起 | 半径 0.35×图标、强度 0.3 | 按压点附近的鼓包。强度再大 CIBumpDistortion 会把图案折叠成黑洞 |
| 拉动弹簧刚度 / 阻尼 | 420 / 28（拖动时）→ 420 / 11（松手后） | 拖动时跟手不抖；松手后阻尼变小，回弹更活泼 |
| 拉动上限 | 图标尺寸 × 1.1（tanh 软限位） | 渐近到上限，永远到不了硬顶，不会「一下拉到头」 |
| 拉伸倍数 | `1 + 0.55 × 拉距 / 图标尺寸` | 上限 1.6 倍，拉距已经过 tanh 软化 |
| 上限阻尼 | 拉距超过 60% 后逐渐加 0～70 | 最后一段像在跟弹簧较劲，不是撞墙 |

三个细节：

1. **局部放大用 CIBumpDistortion**：它是一张只在半径内生效的「放大镜」，
   半径外原样不动，所以看起来是「按的位置肿了一块」，而不是整张图被拉伸。
2. **整体放大绕按压点**：`ctx.scale` 的锚点就是按压点，所以按边上时图标会朝另一侧鼓出去，
   按压点本身保持不动。
3. **窗口不动**：按压、拉动只改绘制时的变换，窗口 frame 从头到尾不参与动画；
   松手让按压弹簧和拉动弹簧都归零，形变自己弹回去。窗口做成 560×560 是给极限形变留余量。
4. **只拉光标那一侧**：拉伸的锚点在「拉动方向反侧的边缘」，所以往左拉时右边界不动、
   左边界伸出去；整体放大一旦检测到拉动就平滑淡出，免得两边一起变长。
   自检里有对应断言：往左拉 130pt 时右边界误差 < 4px。

顺带一句：`Jelly` 里没有任何「窗口偏移」状态，位移在数据层就不存在。

## 自检

```bash
./build/JellyPet.app/Contents/MacOS/JellyPet --self-test
```

检查素材、按压弹簧的冲过头与归位、拉动量、松手后形变归零；用一个合成圆点验证
「只在按压点附近放大、别处不动、中心不偏」；最后离屏渲染闲置 / 按压两帧比较墨迹面积。
检查图会写到系统临时目录的 `jelly-pet-selftest/`。

另外有一个需要辅助功能权限的交互检查，会真的点一下、拖一段，确认窗口坐标全程不动，
跑完把鼠标放回原处：

```bash
swiftc -O Tools/ui-check.swift -o /tmp/ui-check && /tmp/ui-check
```

## 文件

| 路径 | 用途 |
| --- | --- |
| `Sources/main.swift` | 窗口、视图、鼠标交互、菜单、绘制、自检 |
| `Sources/Jelly.swift` | 弹簧和全部形变状态 |
| `Assets/claude-mark.png`、`gpt-mark.png`、`gemini-mark.png` | 三个透明底标志（右键「图标」切换） |
| `Assets/AppIcon.icns` | Finder 里的 app 图标（Claude） |
| `Tools/make-icon.py` | 从 SVG 重新生成三个标志和 app 图标（三颗软糖） |
| `Tools/ui-check.swift` | 合成鼠标事件的交互检查 |

三个标志分别由 `Assets/*.svg` 渲染：Claude 来自 Simple Icons，GPT 来自 Wikimedia Commons
（OpenAI 2025 symbol），Gemini 来自 Simple Icons。渲染后统一去掉白底、按各自的主色重新上色：
Claude 珊瑚 `#D97757`、GPT 绿 `#10A37F`、Gemini 蓝紫渐变 `#4285F4 → #9B72CB → #D96570`。
想换颜色或换回黑白，改 `Tools/make-icon.py` 里的 `ICONS` 再跑一次即可。

代码可自由修改；Claude、ChatGPT/OpenAI、Gemini 的标志与名称是各自公司的商标，
这里只是个人桌面使用。

## 已知限制

- 只支持 arm64 和 macOS 14+；Intel 机器需要把 `build.sh` 里的 `DEPLOY_TARGET` 换成 x86_64 后自行验证。
- 本地 ad-hoc 签名，没有 Apple 公证。从别人手里拿到 dmg 时，用 `./install.sh --from 路径.app`
  安装，它会顺手去掉 `com.apple.quarantine`。
- 只处理鼠标，不处理触控板三指拖动之类的系统手势。
